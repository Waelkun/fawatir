# AI Expense Tracker (مُتتبع المصاريف بالذكاء الاصطناعي)

تطبيق موبايل احترافي متكامل لإدارة وتحليل المصاريف باستخدام الذكاء الاصطناعي (Gemini AI). يتميز بتصميم Fintech داكن فاخر (Premium Dark Mode) مع رسوم بيانية تفاعلية ونظام التعلم الذاتي للمنتجات.

---

## 🏛️ البنية التقنية (Tech Stack)

*   **Front-end**: React Native + Expo (Camera, ImagePicker, custom SVG line/bar charts, React Navigation).
*   **Back-end**: Node.js + Express.js API.
*   **Database**: SQLite (تلقائي للتشغيل الفوري) أو PostgreSQL عبر Prisma ORM.
*   **AI Engine**: Gemini 1.5 Flash (لقراءة الفواتير OCR، توحيد المنتجات، وتوليد الرؤى المالية).
*   **Image Processing**: Sharp (لتحسين جودة صور الفواتير وتصفية التشويش قبل الـ OCR).

---

## 🚀 طريقة التشغيل (Quick Start)

### 1. إعداد الخلفية (Backend Setup)

1.  انتقل إلى مجلد الخلفية:
    ```bash
    cd backend
    ```
2.  افتح ملف `.env` وقم بإضافة مفتاح الـ API الخاص بـ Gemini:
    ```env
    GEMINI_API_KEY="أدخل_مفتاح_gemini_هنا"
    ```
3.  قم بتشغيل سكربت إعداد قاعدة البيانات التلقائي (يقوم بالفحص والتحويل التلقائي لـ SQLite في حال عدم توفر خادم Postgres محلي، وينشئ الجداول ويحقن بيانات الفحص الأولية):
    ```bash
    npm run db:setup
    ```
4.  قم بتشغيل خادم التطبيق (سيعمل على المنفذ `5432` أو `5000` افتراضياً):
    ```bash
    npm run dev
    ```

> 💡 **بيانات حساب الفحص المولد تلقائياً (Seeded Account)**:
> *   البريد الإلكتروني: `alex@fintech.ai`
> *   كلمة المرور: `alexsterling`

---

### 2. تشغيل تطبيق الجوال (Mobile Expo App)

1.  انتقل إلى مجلد تطبيق الجوال:
    ```bash
    cd mobile
    ```
2.  قم بتشغيل خادم Expo:
    ```bash
    npx expo start
    ```
3.  افتح التطبيق عبر:
    *   تطبيق **Expo Go** على هاتفك الشخصي عن طريق مسح رمز الـ QR (تأكد من كتابة الـ IP الخاص بجهازك في صفحة الإعدادات بالتطبيق للاتصال بالسيرفر المحلي).
    *   محاكي الأندرويد (Android Emulator) بالضغط على `a`.
    *   محاكي الآيفون (iOS Simulator) بالضغط على `i`.

## 🌟 الميزات الأساسية المنجزة (Core Features)

1.  **AI OCR Reader (Gemini 1.5 Flash)**: رفع صور الفواتير وتوليد هيكل بيانات JSON يحتوي على بنود الفواتير، الضرائب، والخصومات بدقة متناهية.
2.  **Image Optimization (Sharp)**: معالجة الصور تلقائياً (إزالة التشويش، تحويل للأبيض والأسود، زيادة التباين) لتسهيل القراءة.
3.  **Smart Normalization & Self Learning**: توحيد المسميات المختلفة للمنتج الواحد وحفظها في الذاكرة (مثال: صدور دجاج و Chicken Breast يتم تحويلهما لـ "صدر دجاج").
4.  **Review System**: نظام التحقق الفوري وتلوين الحقول المشكوك بها بنبرة نيون تحذيرية لإمكانية المراجعة السريعة.
5.  **Interactive SVG Charts**: رسوم بيانية خطية وشريطية مخصصة ومصممة بألوان نيون جذابة لرصد منحنى الإنفاق وتطور أسعار السلع الفردية.
6.  **AI Financial Advisor**: توليد نصائح مالية وتنبيهات فروق أسعار تفاعلية ومخصصة باللغة العربية بناءً على نمط استهلاكك الفعلي.
